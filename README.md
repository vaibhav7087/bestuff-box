## 📦 Carton Dimensions & Structure
- **Type**: Straight Tuck End (STE) Folding Carton
- **Trim Dimensions**: **11.2 × 6.0 × 3.0 cm** (112.0 × 60.0 × 30.0 mm)
- **Substrate**: 350 GSM Premium SBS Bleached Board, Matte Soft-Touch Black Finish
- **Embellishments**: Raised Metallic Silver Hot-Foil Stamping + Spot UV Gloss
